# 🪦 Pomolatte: Um Adeus Precoce

Criado por Edgar Henrique, o Pomolatte foi um projeto (não muito) ambicioso de cronômetro Pomodoro unindo React e Spring Boot.

**Motivo do óbito:** O desenvolvedor atingiu a iluminação e percebeu que fazer um `setInterval` no frontend bombardeando a própria API com requisições a cada 1 segundo era, essencialmente, um ataque DDoS auto-infligido. 

Em vez de refatorar para contagem local, optou-se pelo encerramento pacífico das atividades.

Descanse em paz, Pomolatte. Suas requisições infinitas não sobrecarregarão mais nenhum servidor. ☕️💀
